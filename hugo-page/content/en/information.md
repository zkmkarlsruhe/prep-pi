## About This Project

This project, prep-pi, is designed as an offline-first information hub. It runs on a low-power device like a Raspberry Pi, creating a local Wi-Fi network. Anyone nearby can connect to access critical information without needing an internet connection.

### Key Features
- **Offline First**: All content is stored locally.
- **Multi-language**: Supports English, German, and French.
- **Accessibility**: Features high-contrast and dark modes, plus a simplified language option for all content.
- **Low Power**: Designed for minimal hardware.

## What This Is

This is a help center. It works without the internet. You use it on a small computer.

### What It Has
- **Works Offline**: All info is saved here.
- **Many Languages**: It has English, German, and French.
- **Easy to Use**: You can change colors and use simple words.
- **Uses Less Power**: It works on a small computer.
